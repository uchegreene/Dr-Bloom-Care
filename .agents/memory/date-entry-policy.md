description: User-required automatic separators for all typed calendar dates.
---
All typed calendar-date fields should insert the year/month/day separators automatically, not only date of birth.

**Why:** The owner explicitly extended this behavior to last-period dates, pregnancy dates, and wherever else dates are entered.

**How to apply:** Use YYYY-MM-DD consistently, support typing, paste and backspace, and retain each field’s existing date validation. Keep calendar-based selection working; do not change medical calculations or reminder timezones to implement an input convenience.
